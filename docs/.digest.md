# Project Digest

## STACK
- Python 3.12+, TypeScript 7.x SDK and 5.x Web, Node.js 20+, pytest 9.x, Vitest 4.x SDK and 1.6.x Web, Playwright, FastAPI, FastMCP, SQLAlchemy, PostgreSQL, Alembic, Next.js 15.

## ARCHITECTURE
- Pattern: Hexagonal architecture with pragmatic DDD across `api`, `harness_memory_mcp`, `core`, `sdk`, and `web`.
- Layers: Domain invariants; application use cases and ports; infrastructure adapters.
- DI: Constructor injection and explicit handler arguments.
- Web admin: server actions keep admin authority server-side, review credentials, and isolate tokens.
- Project links: Bidirectional cross-tenant project associations managed via REST/Web and returned in MCP `search_projects`.
- MCP guidance: Resolve project/tenant and environment before facts; pin reads to its latest `current_snapshot_id`. `get_history.query` searches entity changes on both sides with historical references.
- MCP summaries: Project environments expose type and published entity counts; environment reads provide counts by type and up to 10 entity references.
- REQUIRED: Enforce unique tenant/project keys; enforce stored token scopes; isolate Web admin credentials server-side; bound reads to active snapshots; publish complete snapshots via REST.
- REQUIRED: Keep SDK and Web on REST; keep persistence adapters and migrations responsible for PostgreSQL.
- PROHIBITED: Framework or persistence imports in domain; unauthenticated tenant authorization; direct database access from SDK or Web.

## TESTING
- Frameworks: pytest 9.x; Vitest 4.x for SDK and Web; Playwright for Web E2E.
- Python: `./venv/bin/python -m pytest tests/unit`; `./venv/bin/python -m pytest tests/integration`; `./venv/bin/python -m pytest tests/e2e`.
- SDK: `npm install`; `npm run lint`; `npm run build`; `npm run typecheck`; `npm run test` from `sdk/`.
- Web: `npm --prefix web run test`; `npm --prefix web run test:e2e`.
- Coverage: Python branch coverage gate is 80% across `api`, `core`, and `harness_memory_mcp`.
- Database: `harness-memory migrate`; inspect with `harness-memory migrate --status`.
