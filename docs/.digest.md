## ARCHITECTURE
- Pattern: Hexagonal Architecture with pragmatic DDD across four components (`api`, `harness_memory_mcp`, `sdk`, `web`).
- Layers: Domain (invariants), Application (use cases, ports), Infrastructure (adapters: PostgreSQL, REST, FastMCP, Next.js BFF).
- DI: Constructor injection and explicit handler arguments.
- Constraints: REQUIRED server-side admin token isolation in Web BFF; REQUIRED active-snapshot bounds on queries; PROHIBITED framework imports in domain; PROHIBITED direct database or Python access from SDK or Web.

## TESTING
- Frameworks: pytest 9.x (Python backend), Vitest (SDK & Web unit), Playwright (Web E2E).
- Commands:
  - Python unit: `./venv/bin/python -m pytest tests/unit`
  - Python integration: `./venv/bin/python -m pytest tests/integration`
  - Python E2E: `./venv/bin/python -m pytest tests/e2e`
  - Python coverage: `./venv/bin/python -m pytest --cov=api --cov=core --cov=harness_memory_mcp --cov-branch --cov-fail-under=80`
  - SDK tests: `npm --prefix sdk run test`
  - Web unit: `npm --prefix web run test`
  - Web E2E: `npm --prefix web run test:e2e`
- Threshold: 80% global backend branch coverage gate.
