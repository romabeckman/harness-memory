# Documentation Digest

## STACK

- Python 3.12+, FastMCP 4.x, Pydantic 2.x, SQLAlchemy 2.x, PostgreSQL, and Alembic.

## ARCHITECTURE

- Pattern: pragmatic DDD organized by business domain.
- Layers: `mcp/` adapters; domain-grouped `core/application/` and `core/domain/`; PostgreSQL infrastructure; Alembic migrations.
- DI: inject repositories and boundary services through constructors or application ports.
- REQUIRED: Keep dependencies pointed inward; keep MCP tools thin; publish immutable versioned snapshots atomically.
- PROHIBITED: Import application/infrastructure or framework details into domain code; trust tenant identity from request payloads.

## TESTS

- Framework: pytest 9.x, pytest-asyncio, pytest-cov, FastMCP in-process client.
- Commands: `pytest tests/unit`, `pytest tests/integration`, `pytest tests/e2e`, `pytest --cov=core --cov=mcp`.
- Coverage: branch coverage; global `fail_under = 80` for `core` and `mcp`; no per-layer gate.
- Database operations: `harness-memory migrate`; read-only status: `harness-memory migrate --status`.
