# Documentation Digest

## STACK

- Python 3.12+, TypeScript 7, Node.js 20+, pytest 9, Vitest 1, FastAPI/FastMCP, Pydantic, SQLAlchemy, PostgreSQL, Alembic, Docker, OpenTelemetry.

## ARCHITECTURE

- Pattern: Hexagonal/pragmatic DDD; components: API, MCP, SDK, Core, PostgreSQL, Alembic.
- Layers: API/MCP adapters; SDK REST; application ports/use cases; domain; PostgreSQL adapters; migrations.
- DI: Inject ports/services through constructors or handler arguments.
- SDK requires agent and complete docs; model is separate. Ignore whitespace-only ADR/feature changes. Return `NO_CHANGES` when docs/graph match; preserve line revisions and mark removed local docs; default ID: project + UTC + UUID.
- SDK preflights target before Git; dry run skips API. Progress/debug stderr; JSON stdout.
- Auth: `API_ADMIN_TOKEN` manages REST; `HARNESS_MEMORY_API_KEY` grants global `memory:read`; DB tokens use stored scopes. REST/MCP share tokens. Authorized reads may span tenants; explicit tenant/project selectors narrow results and trusted scope still applies. `memory:publish` reads targets/baseline and selects destination; impact is MCP-only. Identity/token/account reads need REST admin.
- REQUIRED: Scope DB reads by permission and optional tenant; bound snapshots; verify MCP token digest/owner; use `/v1`; validate schema at startup.
- REQUIRED: Govern MCP components with `ComponentScopePolicy`; publish complete snapshots through REST; derive owner tenant from token; require body `tenant_id` for admin publication.
- REQUIRED: Store snapshot graph facts in normalized entity/relation/evidence rows; preserve REST and SDK payload shapes by reconstructing them; keep MCP reads independent of `snapshots.payload`.
- REQUIRED: List accessible projects with `search_projects` when filters are absent; search current facts by default; pass snapshot IDs from discovery to context; bind cursors to scope and selected snapshot. REST `/v1/entities` uses the MCP search predicate. Publish with an optional expected-current-snapshot precondition; completed deployment retries return recorded identity.
- PROHIBITED: Import framework/persistence details into domain code; trust unauthenticated tenant input; let prompts execute business logic; auto-migrate at runtime.

## TESTS

- Framework: pytest 9.x (backend), Vitest 1.x (SDK).
- Commands: `./venv/bin/python -m pytest tests/unit`; `./venv/bin/python -m pytest tests/integration`; `./venv/bin/python -m pytest tests/e2e`; `npm --prefix sdk run test`.
- Coverage: Branch coverage; global `fail_under = 80` for `api`, `core`, and `harness_memory_mcp`. SDK has no coverage gate.
- Database: `harness-memory migrate`; status: `harness-memory migrate --status`.
- Test folders: `unit`, `integration`, `e2e`; mirror source modules.
