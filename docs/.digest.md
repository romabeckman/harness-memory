# Documentation Digest

## STACK

- Python 3.12+, TypeScript 7, Node.js 20+, Vitest 1, FastAPI/FastMCP, Pydantic, SQLAlchemy, PostgreSQL, Alembic, Docker, OpenTelemetry, pytest.

## ARCHITECTURE

- Pattern: hexagonal architecture across API, MCP, Core, and SDK.
- Layers: API/MCP adapters; SDK publisher; application ports; domain; PostgreSQL infrastructure; Alembic.
- SDK requires an agent via CLI, environment, config, or SDK options; model is independent.
- SDK requires complete docs; skip LLM when ADR/feature text differs only by whitespace. Return `NO_CHANGES` without publishing when docs and graph metadata match baseline. Preserve line revisions; default ID uses project, UTC time, and UUID.
- SDK real publish preflights project, environment, and deployment/version before Git collection; dry run skips API. Progress/debug use stderr; JSON uses stdout.
- API/MCP bearer: admin key grants REST admin; global read key grants `memory:read`; DB tokens use stored scopes. Read scope spans tenants; publish scope reads target metadata and publishes to selected tenant; impact scope grants MCP analysis. Searches filter; users/tokens/service-account reads are admin-only. Admin publication needs body `tenant_id`. CLI: `harness-memory`, `hrns-memo`.
- DI: inject ports and boundary services through constructors or explicit handler arguments.
- REQUIRED: Scope DB reads by permission and optional tenant filter; bound snapshots; verify MCP token digest/owner; use `/v1`; validate schema at startup.
- REQUIRED: Govern MCP tools with `ComponentScopePolicy`; publish complete snapshots through REST. Derive token tenant from owner. Admin publication requires body `tenant_id`.
- PROHIBITED: Import framework/persistence details into domain code; trust unauthenticated tenant input; let prompts execute business logic; auto-migrate at runtime.

## TESTS

- Framework: pytest 9.x (backend), Vitest 1.x (SDK).
- Commands: `./venv/bin/python -m pytest tests/unit`, `./venv/bin/python -m pytest tests/integration`, `./venv/bin/python -m pytest tests/e2e`; `npm --prefix sdk run test`.
- Coverage: branch coverage; global `fail_under = 80` for `api`, `core`, and `harness_memory_mcp`.
- Database: `harness-memory migrate`; status: `harness-memory migrate --status`.
- Test folders: `unit`, `integration`, `e2e`; mirror source modules.
