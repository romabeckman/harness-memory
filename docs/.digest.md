# Documentation Digest

## STACK

- Python 3.12+, TypeScript 7, Node.js 20+, pytest 9, Vitest 1, FastAPI/FastMCP, Pydantic, SQLAlchemy, PostgreSQL, Alembic, Docker, OpenTelemetry.

## ARCHITECTURE

- Pattern: Hexagonal DDD. API, MCP, SDK, Core, PostgreSQL, Alembic. Adapters depend on application/domain; PostgreSQL adapters and migrations own persistence. Inject ports/services.
- SDK: REST publisher requiring agent and complete docs. Preserve line revisions and removed docs; return `NO_CHANGES` for unchanged docs/graph. Preflight target; dry run skips API.
- Auth: `API_ADMIN_TOKEN` manages REST; `HARNESS_MEMORY_API_KEY` grants global `memory:read`; DB tokens use stored scopes across REST/MCP. Reads span tenants unless selectors narrow scope. `memory:publish` selects destination. Impact is MCP-only; identity/token/account reads require REST admin.
- REQUIRED: Scope reads by permission and optional tenant; bound snapshots; verify token digest/owner; use `/v1`; validate schema at startup. Govern MCP components with `ComponentScopePolicy`.
- REQUIRED: Publish complete snapshots through REST; derive owner tenant from token; require body `tenant_id` for admin publication. Store normalized entity/relation/evidence rows; reconstruct REST/SDK payloads; keep MCP reads independent of `snapshots.payload`.
- REQUIRED: List projects with env snapshot IDs; generic search all current envs; history only on request. Pin context; page newest first. Use project active pointer only without env records. Bind cursors to scope/snapshot. REST search shares MCP predicate; publication enforces expected-current and idempotent retries.
- PROHIBITED: Framework/persistence imports in domain; unauthenticated tenant input; prompts executing business logic; runtime auto-migration.

## TESTS

- Framework: pytest 9.x; Vitest 4.x.
- Commands: `./venv/bin/python -m pytest tests/unit`; `./venv/bin/python -m pytest tests/integration`; `./venv/bin/python -m pytest tests/e2e`; `npm --prefix sdk run test`.
- Coverage: Branch coverage; global `fail_under = 80` for `api`, `core`, and `harness_memory_mcp`. SDK has no coverage gate.
- Database: `harness-memory migrate`; status: `harness-memory migrate --status`.
- Test folders: `unit`, `integration`, `e2e` mirror source modules.
